# Data Labeling

This folder contains the scripts and documentation used to assign diagnostic labels to the thyroid scintigraphy images.

## Diagnostic Categories

The dataset was organized into five diagnostic categories:

* Diffuse Goiter
* Hyperfunctioning
* Hypofunctioning
* Multinodular Goiter (MNG)
* Normal

## Labeling Workflow

The labeling process involved:

1. Reviewing the available source records.
2. Matching the relevant examinations with the corresponding imaging studies.
3. Assigning each image to its appropriate diagnostic category.
4. Checking the labeled dataset for consistency.
5. Preparing the labeled data for dataset splitting and model development.

## Data Privacy

The original Excel/source records and patient-related information are **not included in this repository**.

Only anonymized code or documentation should be uploaded.

## Next Step

The labeled images were organized into training, testing, internal validation, and temporal validation datasets.
