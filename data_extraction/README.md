# Data Extraction

This folder contains the scripts and documentation used for extracting thyroid scintigraphy imaging data from the hospital PACS system.

## Workflow

The data extraction process involved:

1. Identifying relevant thyroid scintigraphy studies.
2. Using the available clinical/source records to identify required examinations.
3. Retrieving the corresponding imaging studies from PACS.
4. Organizing the extracted DICOM files for further processing.
5. Preparing the dataset for anonymization and subsequent image processing.

## Data Privacy

The original clinical dataset contains patient-related information and is **not included in this repository**.

No patient-identifiable information, PACS credentials, hospital server details, or restricted clinical data should be uploaded to this folder.

## Next Step

The extracted DICOM data were subsequently anonymized before further processing.
