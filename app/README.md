# Streamlit Application

This folder contains the Streamlit-based application developed as a prototype interface for AI-assisted thyroid scintigraphy classification.

## Purpose

The application provides a simple interface through which a user can provide a thyroid scintigraphy image and obtain a model-based diagnostic prediction.

## Main Features

* Image upload
* Image preprocessing
* Deep learning model selection
* Diagnostic classification
* Display of predicted diagnostic category
* Model prediction output

## Models

The application was designed to support the evaluated deep learning architectures, including:

* ConvNeXt
* DenseNet
* ResNet

## Technology

The application was developed using:

* Python
* PyTorch
* Streamlit
* Image processing libraries

## Important Note

This application is a research prototype and is **not intended to replace professional clinical diagnosis or nuclear physician interpretation**.

No patient-identifiable clinical data are included in this repository.
